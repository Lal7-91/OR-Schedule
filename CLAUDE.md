# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository contents

This is not a software project — it is a document repository for a research effort on Operating Room (OR) scheduling optimization. There is no source code, build system, package manifest, or test suite here, so there are no build/lint/test commands to run.

All content lives under `Docs/`:

- `Optimizing Operating Room Scheduling through Systems Engineering_Abdulmohsen_Alshayeb.pdf` — the core research paper/thesis on OR scheduling optimization.
- `HPC40 - RESEARCH OPPORTUNITIES PROPOSAL.pdf` — a research proposal document.
- `or scheduler 2.pdf` — a related scheduler draft/document.
- `Poster Template- Riyadh - Final.pdf` — a conference/academic poster.
- `OR Schedule Report.xlsx` — a scheduling data/analysis spreadsheet.
- `Docs/Charts/` — photographed chart images (JPGs) used as source material.

## Working in this repository

Tasks here are typically about reading, summarizing, cross-referencing, or editing these documents (PDFs, the spreadsheet, and chart images) rather than writing or running code.
